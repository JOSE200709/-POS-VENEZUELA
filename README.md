# POS Venezuela 🇻🇪

Sistema de Punto de Venta (POS) diseñado para negocios en Venezuela, desarrollado en Python con la librería PyQt6 para la interfaz gráfica.


## 📋 CARACTERÍSTICAS PRINCIPALES
- Interfaz intuitiva y adaptada a necesidades locales.
- Gestión de productos (registro, edición y seguimiento de stock).
- Control de tasa de cambio USD/Bs.
- Panel de estadísticas (ventas totales, ventas del día, clientes activos, etc.).
- Soporte para bancos locales venezolanos.


## 🚀 REQUISITOS PARA EJECUTARLO
- Python 3.8 o superior.
- Librerías necesarias:
  - PyQt6
  - requests
